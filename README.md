# Age of Dinosaurs (공룡의 시대)

와가와가 부족과 함께 **채집하고 · 발전하고 · 막아내라.**
공룡과 야수 무리에 맞서는 **원시시대 로우폴리 3D 채집·디펜스** — AoE 식 자원 운영을 타워 디펜스에 얹었다.

▶ **플레이**: https://skyaicoding.github.io/Wogawoga-Defense/

- 광고 없음 · 결제 없음 · 서버 없음 — 완전 무료 웹게임
- 모든 그래픽·사운드를 코드로 자체 제작 (Three.js 프로시저럴 로우폴리 + WebAudio 합성)
- 아이폰/안드로이드 모바일 브라우저 + 데스크톱 지원 (세로/가로 자동 대응, 세이프 에어리어 대응)

## 게임 소개

- **타워 8종**: 창던지기 움막 · 돌 투석기 · 얼음 크리스탈 · 번개 주술 토템 · 독가시 식물 · 상아 발리스타 · 화염 모닥불 · 전쟁북 — 각 5단계 강화 + 영구 별 업그레이드(1~5성)
- **적 12종 + 보스**: 랩터, 콤피 떼, 트리케라톱스, 프테라노돈(공중), 안킬로사우루스(장갑), 격노 멧돼지, 방패 전사, 힐러 주술사, 매머드, 스피노사우루스, 티라노사우루스, 화산 골렘
- **스테이지 6종**: 초원 → 정글 → 사막 → 설원 → 늪지 → 화산, 스테이지당 50웨이브 (10웨이브마다 보스)
- **무한 모드**: 스테이지 3 클리어 시 해금
- **전투**: 카드 핸드 3장 + 새로고침, 조기 웨이브 호출 보너스, 배속 x1/x2/x4, 자동 웨이브, 타게팅 모드(선두/후미/최강/최근접)
- **자유 배치**: 경로/물/장식물만 아니면 빈 땅 어디든 타워 설치 가능
- **줌/팬**: 핀치(모바일)·마우스 휠(데스크톱)로 줌 인/아웃, 줌 상태에서 드래그로 화면 이동
- **진행**: 호박(보석)과 타워 조각으로 도감에서 영구 강화 — 진행은 기기에 자동 저장(localStorage)

## 실행

```bash
npm install
npm run dev        # 개발 서버
npm run build      # 프로덕션 빌드 → dist/
npm run preview    # 빌드 미리보기
npm test           # 시뮬레이션/데이터 단위 테스트 (vitest)
npm run e2e        # Playwright E2E 스모크
```

## 배포

`claude/primitive-defense-game-7covq4` 브랜치에 push하면 GitHub Actions가 자동으로 GitHub Pages에 배포합니다 (`.github/workflows/pages.yml`).

## 아키텍처

```
src/core/    엔진 유틸 — 고정 타임스텝 루프, 시드 PRNG, 이벤트, 풀링, FSM, 입력, 저장
src/render/  Three.js 렌더링 — 프로시저럴 메시 팩토리, 인스턴싱 뷰, 파티클, 디오라마 카메라
src/sim/     결정론적 전투 시뮬레이션 (three/DOM 의존 없음 — vitest로 테스트)
src/data/    타입 계약 + 밸런스 데이터 (타워/적/스테이지/예산 기반 웨이브 생성기)
src/meta/    영구 진행 (프로필, 보상 정산)
src/game/    통합 글루 (앱 FSM, 전투 컨트롤러, 배치, 연출 라우터)
src/ui/      DOM 오버레이 UI (i18n ko/en)
src/audio/   WebAudio 프로시저럴 사운드 (SFX 합성 레시피 + 생성 음악 시퀀서)
```

핵심 설계:

- **결정론 시뮬레이션**: 30Hz 고정 틱 + 렌더 보간, 커맨드 in / 이벤트 out. 같은 시드 = 같은 판 (CI에서 2000틱 해시 동일성 검증)
- **드로우콜 예산**: 지형 정적 병합, 적/투사체/파티클/체력바 전부 인스턴싱, **타워는 `BatchedMesh` 묶음 여섯**(몇 기를 세우든 드로우콜이 늘지 않는다 — 실측 40기 130콜 → 14콜). E2E가 프레임 종류별로 따로 어서션한다 — 합성 최악 프레임 ≤56콜(실측 41~43) / 150,000삼각형, 가벼운 전투 프레임 ≤24콜(실측 17), 비전투 디오라마 배경 ≤14콜(실측 10~11)
- **난이도 봉투 CI 고정**: 자동플레이 봇이 스테이지1을 클리어할 수 있고, 방치는 반드시 패배하며, 스테이지6은 별 없이 못 깨는 것을 테스트로 보장
- **모바일 대응**: DPR 상한 + 프레임타임 기반 동적 해상도, iOS 오디오 언락, 세이프 에어리어, 화면 꺼짐 방지(Wake Lock)
